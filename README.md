# 🧮 Math Geniuses Store

An interactive educational rewards system designed to help teachers manage student points, rewards, and classroom achievements in a simple and engaging way.

## ✨ Features

- Create, edit, and delete classes
- Add, edit, and remove students
- Add or deduct points for individual students
- Award points to multiple students at once
- Track point and reward activity
- Create and manage custom rewards
- Automatically deduct points when a reward is redeemed
- Select the Student of the Month based on the highest point balance
- Support multiple winners in case of a tie
- Generate printable Student of the Month certificates
- Print or save certificates as PDF
- Export and import data backups
- Responsive design for mobile, tablet, and desktop devices

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git & GitHub
- Cloudflare

## 💡 About the Project

Math Geniuses Store was developed as a classroom motivation and rewards system.

Teachers can manage classes and students, award points for achievements and participation, and allow students to redeem their accumulated points for rewards.

All student management, point transactions, and reward redemptions are controlled by the teacher.

## 💾 Data Storage

The project uses `LocalStorage` to store data locally in the user's browser.

A backup system is also included, allowing data to be exported and restored when needed.
